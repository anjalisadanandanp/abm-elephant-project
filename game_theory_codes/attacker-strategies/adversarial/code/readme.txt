Adversarial: an attacker with the maximin mixed strategy. 
That is, the attacker is fully adversarial – he only cares about minimizing the defender’s utility.

Game model: two player zero-sum game
Minimax: strategy of minimizing the maximum possible loss
Maximin: strategy of maximizing the minimum possible payoff

From an attackers perspective, this translates to finding minimax strategy (attackers gain is defenders loss due to zero-sum property).
Finding mixed strategy that minimizes the maximum possible loss for the attacker, which is minimizing the maximum possible payoff for the defender.
